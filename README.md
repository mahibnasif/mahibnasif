## About me

I build products across the full stack, from backend services and data models to
responsive interfaces, automated tests, and cloud infrastructure. My main work
uses **Java and Spring Boot** or **TypeScript, React, and Node.js**, backed by
relational databases and production-style delivery tooling.

I care about what happens beyond the happy path: authorization boundaries,
concurrent state changes, failure recovery, observability, security, and
repeatable deployments.

- Built a multi-tenant monitoring and incident-response platform with automated
  health checks, live updates, reliability analytics, and an AWS deployment
  target.
- Built an autonomous GitHub research agent that plans its own tool use, adapts
  to evidence gaps, and delivers citation-verified reports with bounded execution.
- Helped engineer an ESP32 fall-detection wearable and its cloud-connected
  caregiver dashboard.
- Previously worked in UI/UX design and pharmaceutical IT environments.
